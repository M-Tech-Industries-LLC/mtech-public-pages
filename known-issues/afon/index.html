Private Session — External Application Tab Cleanup

Some incoming links opened during Private Session may leave temporary tabs open after launching an external application. This occurs when Afon cannot safely establish that the tab belongs exclusively to the external application handoff. Normal browsing-session external application cleanup is unaffected.
