# Afon Build 28 Theme Registry

Build 28 reads `https://m-techindustries.com/themes/afon/registry.json`. This registry lists all nine themes and retains its existing version-1 schema and production package/checksum URLs. GitHub Pages remains a compatibility host; do not remove or repoint resources without a separate dependency review.

The human-readable catalog is [/afon/themes/](../../afon/themes/index.html). Package names may use “The Reading Room” and a straight apostrophe in Afterglow '86; public display names are Reading Room and Afterglow ’86. Ice retains an experimental status in runtime metadata; its inclusion in the Owner’s nine-theme Build 28 catalog does not authorize changing that status here.

The separate `/afon/themes/catalog.json` reference catalog contains three entries and a different schema. It must not be treated as the full Build 28 inventory or substituted for this registry. Theme packages and entitlement validation remain separate from public website content.
