Version 0.1.0-beta

  • Status: Initial public/testing release
  • Product: Aevon

Overview

This is the initial mobile browser testing release for Aevon. It is intended to support early public testing and feedback.

Added

  • Basic browsing support.
  • Personal bookmark support.
  • Managed bookmark awareness.
  • Browser data clearing controls.

Improved

  • Privacy-focused settings language.
  • Initial app relaunch and session handling behavior for testing.
  • Managed configuration support continues to evolve.

Privacy/Security

  • Browser data clearing controls are available for testing.
  • Settings and managed configuration behavior are documented in the Aevon Privacy Policy.
  • Security concerns can be reported through the public security contact page.

Known Limitations

  • Session handling and app relaunch behavior are under review.
  • Device back button navigation is under review on Android.
  • Managed configuration support is evolving.
