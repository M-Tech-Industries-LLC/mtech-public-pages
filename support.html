Afon Browser help

Current distributed testing release: 0.1.3+28, through Google Play for Android and TestFlight for iPhone and iPad. Start with the known issues, release notes, or downloads and testing information.

Why did a temporary tab stay open?

In Private Session, an incoming external-app link can leave a temporary tab when Afon cannot safely establish exclusive handoff ownership. You can close the leftover tab manually. Normal browsing-session cleanup is unaffected.

Why is an HTTP link blocked?

Insecure HTTP navigation remains blocked. Use Try HTTPS or Edit Address when offered. HTTP Continue Once is unavailable.

Where is Strict Link Protection?

Standard is the default. Strict is available on Android and is not available in the iOS / iPadOS release.

How do I manage external applications and location access?

Review saved application decisions in Afon’s Approved Applications settings. Private Session handoffs use one-time approval. For website location requests, review both the website permission and the device’s location permission for Afon.

How do I get themes?

Review the nine-theme catalog. Use Theme Manager in Afon with your theme’s unlock code. Downloading a package alone does not grant entitlement.

How do I report a website problem?

Include the installed build, device/OS, Standard or Strict mode, normal or Private Session, and safe steps to reproduce. Providers may still show verification or consent pages. Remove personal query parameters and private information from any example links.
