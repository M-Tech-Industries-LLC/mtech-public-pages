Report a Concern

Report security concerns to support@m-techindustries.com.

Please avoid public disclosure of potential security issues until they have been reviewed.

What to Include

If safe to share, include the affected app, app version, device or platform details, and reproduction details.

Notes

Submitting a report does not create a bounty promise or response-time commitment.
